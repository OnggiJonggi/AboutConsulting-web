TA(Text Analytics)
  : 자연어로 작성된 텍스트에서 중요 정보를 뽑아내는 기술
  1. 문제 정의
  2. 데이터 수집, 전처리
  3. 특징화(임베딩 등)
  4. 분석/모델링
  5. 결과 해석

NLP(Natural Language Processing)
  : 컴퓨터가 인간 언어를 이해/처리하는 전반적인 기술.

원-핫 인코딩
  : 단어 집합 크기만큼 벡터 생성. 있으면 1, 없으면 0
  : 단어가 많아질수록 차원이 커짐
  : 존재 유무만을 판별

정수 인코딩
  : 단어에 고유 번호 부여
  : 벡터X, 리스트/배열로 저장됨

Bag of Words(BOW)
  : 텍스트 중 단어의 빈도를 벡터화
  : 문맥 반영 안됨

TF-IDF(Term Frequency-Inverse Document Frequency)
  : 텍스트 내 단어 빈도 X 다른 텍스트에 많이 등장할수록 가중치 낮음
  : 흔한 단어의 가중치를 줄여 핵심 키워드 추출

텍스트 임베딩
  : 텍스트를 의미 벡터 공간에 맵핑
  : 비슷한 단어를 공간상 가까운 위치에 두기에 단어 간 의미 관계 반영 가능

차원 축소
  : 데이터를 작은 차원으로 줄임
  : PCA(주성분 분석) - 데이터의 분산이 가장 많은 방향으로 차원 축소. 데이터 보존 높음
  : t-SNE(티분포 확률적 임베딩)
  : SVD(특이값 분해)
  : 스파스 랜덤 투영

유클리드 거리 계산
  : 두 벡터 간 실제 거리
