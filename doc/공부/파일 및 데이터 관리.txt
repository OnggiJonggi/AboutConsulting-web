비트마스크 : 여러 불리언 값을 하나의 정수로 저장
    비트 연산 으로 빠른 연산 가능, 효율적인 메모리 사용
    예) 권한 관리

magic bytes(혹은 file signiture) : 파일 가장 앞에 위치해 파일 포맷을 나타내는 바이트
    바이너리 파일은 매직 바이트로 어떤 포맷인지 나타냄.
    없는 경우도 있음.

MIME 타입(Multipurpose Internet Mail Extensions) : 인터넷에서 파일을 주고 받을 때 파일이 어떤 포맷인지 알려주는 역할
    요청 헤더(Content-Type)에 담겨서 보내짐.
