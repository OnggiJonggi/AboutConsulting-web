동기 통신
  : 브라우저가 요청을 보낸 후 응답을 받을 때 까지 대기
  : 대기 중에 브라우저 UI를 포함한 다른 동작을 하지 않음
  : ex) 간단한 정보 조회, 페이지 이동

비동기 통신
  : 브라우저가 요청을 보낸 후 응답을 받기 전 다음 동작 실행
  : 브라우저의 UI가 멈추지 않음
  : 페이지 일부 정보 업데이트

스프레드 연산자
  : ex) const arr = [2, 3];
    const extended = [1, ...arr, 4]; // [1, 2, 3, 4]
    const [first, ...rest] = [1, 2, 3, 4]; // first = 1, rest = [2, 3, 4]
